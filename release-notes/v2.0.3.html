Lumi 2.0.3: на Linux — без AppImage 🐧👻 Теперь Lumi на Linux ставится как обычная программа: через пакет для вашей системы. Что нового • Ubuntu, Debian, Mint — файл .deb: sudo apt install ./Lumi-2.0.3-amd64.deb • Fedora — файл .rpm: sudo dnf install ./Lumi-2.0.3-x86_64.rpm • Lumi появляется в меню приложений, FUSE больше не нужен. Ошибка «AppImage ругается на FUSE» остаётся в прошлом. • Для остальных дистрибутивов AppImage никуда не делся. • Если Lumi запускается при входе в систему, она сама переключит автозапуск на новую копию, когда вы её откроете. На Mac и Windows всё по-прежнему. Как обновиться: на Linux скачайте .deb или .rpm со страницы выпуска и установите. Откройте Lumi один раз, после этого старый AppImage можно удалить. Настройки, горячая клавиша и модели сохранятся.
