v2.0.42026-11-04

Lumi 2.0.4: Ctrl+Пробел на Linux снова работает

🐧👻

Если у вас Ubuntu, Fedora или другой Linux с рабочим столом GNOME, Lumi могла не открываться по Ctrl+Пробел.

Что было

  • Lumi записывала сочетание клавиш в настройки GNOME, но сама команда запуска не сохранялась. Клавиша нажималась — и ничего не происходило.
  • Нашли ошибку, когда проверяли Lumi на чистой системе.

Что исправлено

  • Команда теперь сохраняется правильно, Ctrl+Пробел открывает строку.
  • Lumi заново записывает сочетание при каждом запуске, поэтому после обновления всё заработает само.

На Mac и Windows всё по-прежнему.

Как обновиться: скачайте .deb, .rpm или AppImage со страницы выпуска и установите поверх. Откройте Lumi один раз — и пробуйте Ctrl+Пробел.

v2.0.32026-11-03

Lumi 2.0.3: на Linux — без AppImage

🐧👻

Теперь Lumi на Linux ставится как обычная программа: через пакет для вашей системы.

Что нового

  • Ubuntu, Debian, Mint — файл .deb: sudo apt install ./Lumi-2.0.3-amd64.deb
  • Fedora — файл .rpm: sudo dnf install ./Lumi-2.0.3-x86_64.rpm
  • Lumi появляется в меню приложений, FUSE больше не нужен. Ошибка «AppImage ругается на FUSE» остаётся в прошлом.
  • Для остальных дистрибутивов AppImage никуда не делся.
  • Если Lumi запускается при входе в систему, она сама переключит автозапуск на новую копию, когда вы её откроете.

На Mac и Windows всё по-прежнему.

Как обновиться: на Linux скачайте .deb или .rpm со страницы выпуска и установите. Откройте Lumi один раз, после этого старый AppImage можно удалить. Настройки, горячая клавиша и модели сохранятся.

v2.0.22026-10-29

Lumi 2.0.2: призрак надел шляпу

🎃👻

С 24 октября по 1 ноября у Lumi хэллоуин: призрак носит шляпу ведьмы, а кнопки и ссылки становятся тыквенно-оранжевыми.

Почему вы могли этого не заметить

  • Lumi проверял дату только при запуске. Если программа была открыта с начала октября и компьютер не перезагружался, праздник так и не наступал.
  • Теперь дата проверяется каждый раз, когда вы открываете строку. Это касается Mac, Windows и Linux.

Как обновиться: на Mac и Windows Lumi сама покажет «Доступна Lumi 2.0.2 — скачать». На Linux скачайте новый Lumi-x86_64.AppImage со страницы выпуска. После обновления шляпа появится сразу.

Шляпа будет до 1 ноября включительно, а потом снимется сама 👋

v2.0.12026-10-13

Lumi 2.0.1: свои модели знают вашу систему

👻🐧

Небольшое, но полезное обновление.

Модели Lumi отвечают про вашу систему

  • Раньше на вопрос «как посмотреть, сколько места на диске?» lumi могла рассказать про Windows, хотя вы сидите на Linux. Теперь lumi-mini, lumi и lumi-pro знают, на какой системе работают, и отвечают для неё: на Linux — df -h, на Mac — «Об этом Mac», на Windows — Проводник.
  • Уже установленные модели обновятся сами при запуске Lumi: за пару секунд, ничего заново не скачивается.

Сообщить об ошибке — в один клик

  • В меню Lumi появился пункт «Сообщить об ошибке…». Он открывает форму на GitHub, где уже заполнены версия Lumi, система и выбранная модель. Ключи и адреса серверов туда не попадают.
  • Пользователям Linux это особенно поможет: в форму подставляются дистрибутив и рабочий стол, так мы быстрее найдём причину.

Как обновиться: на Mac и Windows Lumi сама покажет «Доступна Lumi 2.0.1 — скачать». На Linux скачайте новый Lumi-x86_64.AppImage со страницы выпуска.

v2.0.02026-10-10

Lumi 2.0: теперь и на Linux

🐧👻

Вы просили, и вот: Lumi работает на трёх системах — Mac, Windows и Linux.

Lumi для Linux

  • Один файл AppImage: скачали, разрешили запуск, открыли. Рассчитана на Ubuntu, Fedora, Debian и другие дистрибутивы для обычных компьютеров (x86-64).
  • Всё, что умеет Lumi: ответы Claude, ChatGPT и Gemini по вашей подписке, OpenRouter и другие сервисы, запуск приложений и поиск файлов, пять языков интерфейса.
  • ИИ без интернета одной кнопкой: Lumi сама поставит Ollama в вашу домашнюю папку (без пароля администратора, с проверкой контрольной суммы) и настроит свою модель.
  • Горячая клавиша по умолчанию Ctrl+Пробел: привычный Alt+Ё в GNOME и KDE уже занят системой. В GNOME Lumi назначает клавишу сама.

Это первая версия для Linux. Если что-то работает не так, напишите нам: поправим быстро.

Своя горячая клавиша — на всех системах

  • В окне Lumi нажмите «Изменить» под клавишами и задайте любое сочетание, например Ctrl+Пробел или F5.
  • Если сочетание занято другой программой, Lumi скажет об этом и оставит прежнее.
  • «Сбросить» возвращает клавишу по умолчанию.

Как обновиться: на Mac и Windows Lumi сама покажет «Доступна Lumi 2.0.0 — скачать». На Linux скачайте Lumi-x86_64.AppImage со страницы выпуска.

v1.5.02026-10-10

Lumi 1.5.0: ИИ без интернета, теперь в одну кнопку

👻⚡

Раньше для своих моделей Lumi нужно было сначала отдельно скачать и установить Ollama. Теперь не нужно.

  • Всё одной кнопкой. «Подключить модель…» → Ollama → «Установить Lumi». Если Ollama на компьютере нет, Lumi сама скачает её, установит, запустит, а потом поставит модель.
  • Безопасно. Lumi ставит Ollama только с официального сайта и только если файл подписан разработчиком Ollama. Подменённый файл Lumi не установит.
  • Права администратора не нужны.

Размер загрузки: Ollama занимает 0.2 ГБ на Mac и 1.6 ГБ на Windows (в ней библиотеки для видеокарт), плюс сама модель от 4.6 ГБ. Всё скачивается один раз, дальше Lumi работает без интернета.

Как обновиться: Lumi сама покажет «Доступна Lumi 1.5.0 — скачать» в меню. Или скачайте новую версию и установите поверх старой, настройки сохранятся.

v1.4.02026-10-10

Lumi 1.4.0: у призрака теперь свой мозг

👻🧠

Свои модели Lumi работают прямо на компьютере, без интернета, и ваши вопросы никуда не уходят.

  • Установка одной кнопкой. «Подключить модель…» → Ollama → «Установить Lumi». Lumi сама подберёт размер под ваш компьютер, скачает модель с полоской прогресса и всё настроит. Терминал не нужен.
  • Три размера:

— Lumi Mini (4.6 ГБ): для ноутбуков с 8 ГБ памяти;

— Lumi (6.6 ГБ): для большинства компьютеров с 12–16 ГБ;

— Lumi Pro (24 ГБ): самая умная, для мощных компьютеров от 32 ГБ.

  • Модели настроены под Lumi: отвечают коротко, на языке вопроса и пишут готовые сообщения, которые можно сразу отправить. Мы сравнили несколько открытых моделей на одних и тех же вопросах и выбрали лучшие по качеству ответов на русском.
  • Быстрые ответы: «думающие» модели в Ollama, например Qwen 3.5 и 3.6, раньше могли размышлять полминуты. Теперь они отвечают за секунду-две.
  • Если загрузка прервётся, нажмите кнопку ещё раз: Lumi продолжит с того же места.

Для своих моделей нужна бесплатная программа Ollama. Если её нет, Lumi даст ссылку на скачивание.

Как обновиться: Lumi сама покажет «Доступна Lumi 1.4.0 — скачать» в меню. Или скачайте новую версию и установите поверх старой, настройки сохранятся.
